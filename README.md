1PM Club Pre-Order Website

The 1PM Club is a mobile-first Progressive Web Application designed for office-based café pre-orders. Its primary purpose is to allow customers to browse the café menu, customize drinks, schedule pickup times, place pre-orders, and monitor order status without waiting physically at the café. The visual direction follows the branding provided in the project reference, including the blue and purple switchable themes, light background, and Coffee, Matcha, Hōjicha, and drink add-on categories.
